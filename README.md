# Artist Link Hub

A mobile-first music artist link-in-bio page built with plain HTML, CSS and JavaScript.

## Included

- Artist name, bio and profile image
- Spotify
- Apple Music
- YouTube
- Audiomack
- TikTok
- Instagram
- Custom profile editor
- Responsive mobile/desktop layout
- Browser-local profile persistence
- Share-profile button

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy

This is a static site, so it can be deployed to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or another static host.
